# Steam delivery files

This directory contains only version-controlled release inputs. It never stores Steam credentials or a real Steamworks App ID.

## Directories

- `scripts/` contains SteamPipe templates for the packaged Windows build.
- `store/screenshots/` contains automated 1920 × 1080 captures from the running Electron/WebGL game.
- `output/` is generated by SteamCMD and ignored by Git.

## Prepare an upload

1. Run `npm.cmd run release:check` on Windows.
2. Copy both files from `scripts/` to private, untracked filenames.
3. Replace `YOUR_APP_ID` and `YOUR_WINDOWS_DEPOT_ID` with values from Steamworks.
4. Keep `Preview` set to `1` for the first SteamPipe pass.
5. Upload with the Steamworks SDK ContentBuilder, inspect the manifest, and then promote the verified build to a private Steam branch.

The launch option in Steamworks must point to `ORBIT-04.exe`. Steam account credentials must not be committed to this repository.
