# ORBIT//04 — Steam store copy draft

All statements below describe the current top-down Windows build. Recheck numerical claims against the release candidate before submitting the store page.

## Short description

Pilot one of ten combat frames through focused 12-minute space-survival runs. Move, dash, combine eleven automatic weapon systems, defeat three escalating bosses, and turn a successful run into a harder Ascension.

## About this game

ORBIT//04 is a single-player tactical space-survival game built around positioning, readable threats, and fast build decisions. Your weapons fire automatically; your job is to steer through hostile formations, time the Phase Dash, collect upgrades, and decide how aggressively to extend each run.

### Build a combat system

Choose from ten frames with distinct statistics, traits, and starting equipment. Upgrade eleven weapon families, complete evolutions, activate cross-weapon synergies, and shape each run with doctrines, contracts, artifacts, and research.

### Survive a defined campaign

A standard run lasts 12 minutes and contains three boss encounters. Four sectors and three difficulty settings change the pressure around a consistent objective. Victory can end the run or open Ascension mode for stronger enemies and higher multipliers.

### Keep long-term progress

Earn credits, improve persistent research, raise frame mastery, complete operations and achievements, and expand the in-game Codex. Saves remain local and include an automatic backup plus manual export and import controls.

## Implemented feature bullets

- single-player top-down space survival
- ten combat frames and eleven automatic weapon systems
- weapon upgrades, evolutions, synergies, doctrines, artifacts, and contracts
- four sectors, three difficulty modes, and three scheduled bosses
- optional endless Ascension after a successful standard run
- keyboard, mouse, and gamepad movement
- configurable interface scale, motion, contrast, effects, and audio mix
- offline play with local save backup and export/import
