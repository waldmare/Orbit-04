# ORBIT//04

Lightweight browser-based space survivor inspired by early-2000s mobile games.

## Status

Early prototype.

## Current features

* Automatic shooting
* WASD / arrow-key movement
* Enemy waves
* XP and leveling
* Random upgrades
* Increasing difficulty
* Score system

## Tech

* HTML
* CSS
* JavaScript
* HTML5 Canvas
* No dependencies
* No build process

## Run locally

Open `index.html` in a browser.
