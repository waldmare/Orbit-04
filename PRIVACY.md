# Privacy

ORBIT//04 does not collect analytics, advertising identifiers, account information, or gameplay telemetry. The game does not require a network connection during play.

Progress and settings are stored locally through the Electron application profile. The game maintains a local backup and supports manual save export and import. Diagnostic errors may be written to a local `logs/orbit.log` file inside the application's data directory; the file is not uploaded automatically.

If a future release adds online services, crash reporting, cloud saves, or account features, this notice must be updated before those features are enabled.
