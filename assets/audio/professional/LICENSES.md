# Professional audio sources

The files in this directory are selected and, where noted, edited versions of freely licensed sound effects. File names were changed to match their runtime purpose in ORBIT//04.

## Lentikula — Sci-Fi Weapon Shots SFX

- Runtime directory: `lentikula/`
- Original pack: https://lentikula.itch.io/sci-fi-weapon-shots-sfx-freecc0
- License: Creative Commons Zero 1.0 Universal (CC0-1.0)
- Source format: stereo WAV, 48 kHz, 24-bit
- Production note: the author states that the pack was made from a sample library, synthesizers and original recordings without generative AI.

## ObsydianX — Interface SFX Pack 1

- Runtime directory: `obsydianx/`
- Original pack: https://obsydianx.itch.io/interface-sfx-pack-1
- License: Creative Commons Zero 1.0 Universal (CC0-1.0)
- Source format: stereo WAV, 44.1 kHz, 16-bit
- Runtime edits: selected cues were trimmed, level-matched, faded and resampled to 48 kHz stereo PCM.
